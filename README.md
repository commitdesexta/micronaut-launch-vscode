# Micronaut Launch for VS Code/VSCodium

Create Micronaut projects directly from VS Code and VSCodium using the Micronaut Launch API.

## Features

- Language selection (Java, Kotlin, Groovy)
- Build tool selection (Gradle, Gradle Kotlin, Maven)
- Java version selection
- Automatic project download
- Automatic ZIP extraction
- Automatically opens the created project

## How to use

1. Open the Command Palette
2. Run "Micronaut: Create Project"
3. Follow the wizard steps

## Requirements

- Java 17 or higher
- Internet connection
